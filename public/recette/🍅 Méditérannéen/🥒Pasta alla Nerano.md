## 👨‍🍳 Étapes

1. Couper les courgettes en lamelles
2. Frire rapidement les courgettes
   1. Ajouter du basilic pour absorber
3. Cuire les pâtes d'un côté
4. De l'autre
   1. Huile olive + 2 gousses d'ail rapé + tiges de basilic
   2. Ajouter de l'eau de cuisson,
5. Une fois les pâtes cuites
   1. Ajouter les pâtes dans la poele
   2. Eteindre le feu
   3. Basilic, courgette, parmesan => crême
