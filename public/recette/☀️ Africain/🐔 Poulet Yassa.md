## 👨‍🍳 Étapes

1. **Préparer la marinade :**  
   Assaisonner le poulet. Couper les oignons. Marinade : jus citron + ail + moutarde + (optionnel : piment)

2. Mariner 12h min le poulet au frais
3. Faire dorer le poulet avec de l'huile, puis réserver
4. Faire revenir les oignons jusqu'à caramélisation
5. Ajouter le poulet+ la marinade + feuilles de laurier + jus restants
6. Ajouter de l'eau, assaisonner, laisser cuire le poulet
7. Ajouter quelques olives
8. Servir avec du riz

## 💡 Conseils

- Variante sans lactose : utiliser lait végétal.
- Pour une version sucrée/salée : ajuster les épices.
